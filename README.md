# Solids.AI.Repo

This repository is a shared home for reusable AI skills, agents, prompts, and
instructions used by Solids team members.

## Contents

Store assets in the standard GitHub Copilot locations:

- `.github/skills/` — reusable skills; give each skill its own directory with a
  `SKILL.md` file.
- `.github/agents/` — custom agent definitions (`*.agent.md`).
- `.github/prompts/` — reusable prompt files (`*.prompt.md`).
- `.github/instructions/` — reusable instruction files (`*.instructions.md`).

Organize related assets together and use descriptive names so teammates can
find and reuse them.

## Contributing

Contribute assets that are useful across the team, with clear descriptions and
the context needed to use them. Keep guidance general rather than tied to
individuals or private projects, and never include credentials, secrets, or
other sensitive information. Update an asset when its related workflow changes
and remove it when it is no longer useful.
